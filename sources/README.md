# 原始资料区

将待学习的教材、论文、赛题、讲义、代码和数据说明放在本目录或按主题建立子目录。

约定：

1. 原文件只读保存，不覆盖、不改名丢失来源信息；
2. 记录来源链接、作者、版本和获取日期；
3. 阅读后使用上级目录的 `资料消化模板.md`；
4. 将可复用结论写入对应专题，而不是只留阅读笔记；
5. 外部公式、图表、数据和结论在正式报告中按规范引用；
6. 涉及许可、隐私或保密的资料不得随意复制到公开交付物。
7. 关键来源、访问日期、证据等级和文件哈希登记到 `来源与证据台账.md`。
8. 搜索摘要和二手转载只用于定位原始来源，不直接沉淀结论。

## 默认读取边界

- `sources/` 是证据保全区，不是每次建模的默认上下文；
- 只有追溯公式、数据、奖项、软件版本或复现实验时，才按来源 ID 打开具体记录和原件；
- PDF、图片、代码和状态 JSON 的存在不等于内容已核验；核验状态以审读记录和台账为准；
- 自动学习记录属于候选与审计证据，未通过门禁的内容不得迁移到主专题；
- 不为整理目录而移动或重命名已有原件，除非同步更新台账、哈希记录和所有引用。

## 推荐子目录角色

| 位置 | 角色 |
|---|---|
| `原文/` | 官方或合法取得的原始资料及页面保全 |
| `美赛/`、其他赛事目录 | 按赛事和队号保存全文、审读记录与复核脚本 |
| `自动学习/` | 定期搜索、候选核查和未通过准入的记录 |
| `来源与证据台账.md` | 全局来源 ID、主张用途、版本、访问日期和哈希入口 |
