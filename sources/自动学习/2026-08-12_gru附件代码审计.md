## 2. 已复现的阻断问题

### 2.1 `view` 不是轴交换

附件第 117--120 行先得到 `[B,T,C]`，随后使用：

```python
x = x.view(x.size(0), x.size(2), x.size(1))
x = self.batch_norm(x)
x = x.view(x.size(0), x.size(2), x.size(1))
```

`view` 只按新的形状解释同一线性内存，不会把时间轴和通道轴换位。`BatchNorm1d(C)` 对三维输入要求
`[N,C,L]`；正确轴变换应使用 `x.transpose(1, 2)`，归一化后再转回。确定性张量
`arange(24).reshape(2,3,4)` 上，错误 `view(2,4,3)` 与正确 `transpose(1,2)` 的最大元素差为 6。

### 2.2 MSE 广播改变目标函数

网络正常回归输出为 `[B,1]`，而滑窗目标由一维数组构造为 `[B]`。附件第 303--304、378--379 行
直接计算 `criterion(outputs, targets)`。按 PyTorch 广播规则，两者会扩展为 `[B,B]`，不是逐样本
一一对应。确定性小例：

- prediction=`[[1],[2],[3]]`，target=`[1,2,5]`；
- 广播后张量形状 `[3,3]`，MSE=4.0，并产生警告；
- `prediction.squeeze(-1)` 后正确逐元素 MSE=1.3333333731。

这是目标函数错误，必须在任何训练前修正，并加入 `assert outputs.shape == targets.shape`。

### 2.3 时间滑窗泄漏

附件第 219--223 行以步长 1 创建强重叠窗口，随后第 229--238 行调用两次
`train_test_split(..., shuffle=True)`。相邻窗口共享 `seq_len-1` 个时点，随机拆分会让几乎相同的
历史片段跨训练、验证和测试，且可能用未来窗口训练、过去窗口测试。

正确顺序是先按部署时间切分原始序列，再在各段内部建窗；切分边界按最大输入窗口、标签预测期和特征
回看期设置隔离 gap。若有多个主体，还必须先按主体/时间联合隔离。

## 3. 其他高风险问题

1. `h_0` 文档写成 `[batch,seq,input]`；PyTorch 单向 GRU 的批输入隐藏状态应为
   `[num_layers,batch,hidden_size]`，双向时首维再乘 2。
2. `output_type` 未限制为 `last/mean`；非法值会保留时间轴，实测输出 `[7,6,1]`，违反文档所称
   `[batch,output_size]`。
3. `mean` 池化不知道 padding/mask，变长序列会把填充值计入平均。
4. `nn.GRU(dropout=p)` 在 `num_layers=1` 时不产生层间 dropout；配置必须说明。
5. 注释称全连接层“orthogonal initialization”，实际使用 Xavier；GRU 拼接门权重整体做正交初始化
   也不同于逐门初始化，应记录选择而非把两者混称。
6. 随机性控制不完整：没有统一设置 Python/NumPy/DataLoader worker/CUDA 与 deterministic 选项。
7. 缓存文件名没有绑定原 CSV 哈希、`seq_len`、比例和种子；参数变化后可能静默读取旧划分。
8. 设备判断只检查“任一 CUDA/MPS 可用”，不检查请求的具体后端；配置 `mps` 而仅 CUDA 可用时仍会
   选择不可用的 `mps`。
9. 若首次验证分数为 NaN，`counter` 可能尚未初始化；`patients` 计的是验证次数，日志却称 epoch。
10. 训练/验证损失以“批均值的均值”汇总；最后批较小时权重错误。两批大小 2、1、批损失 1、9 时，
    当前汇总为 5，逐样本加权值为 11/3。
11. 最佳检查点只保存不回载；主函数丢弃 `X_test,y_test`，没有独立最终测试结果。
12. `torch.load` 缓存只应读取可信本地文件；反序列化边界和具体版本参数要明确。

## 4. 最低修复顺序

1. 先按时间/主体切原序列，训练段拟合缩放器，各段内部建窗并设 gap。
2. 用 `transpose` 修复 BatchNorm 轴；或改用更适合序列的归一化并明确归一化维度。
3. 强制输出/目标同形，加入 forward、loss 与单批过拟合测试。
4. 校验 `output_type`、设备、比例、空数据集、NaN 和缓存元数据。
5. 损失按元素或样本数加权汇总，回载最佳检查点，只在最后一次使用测试集。
6. 与季节朴素、线性/正则模型、固定窗口 MLP 在同一滚动回测协议下比较。
