## 2. 核验流程

1. 将原图片中的术语去重并纠正身份，例如线性回归与 OLS、分层进入与多层模型、稳健回归与具体损失。
2. 按响应支持集、依赖结构、目标和验证单位分类，不以算法流行度分类。
3. 每条只保留一个必要基本式、最合适场景、核心优点和最危险边界。
4. 对高风险公式独立复核：ARIMAX 写成回归加 SARIMA 误差；VECM 写出协整秩；AIPW 写出增广项；
   空间模型写清 `W`；删失、截断、零膨胀和 Hurdle 分开。
5. 对前沿方法只记录可核验能力和版本边界，不写“必然更准”或“最先进”。
6. 最终通过表格列数、公式定界符、来源 ID 覆盖、本地链接和知识库验证脚本检查。

## 3. 关键纠错结论

- OLS、GLS、2SLS、GMM、AIPW 等首先是估计方法；因果性来自研究设计与识别假设，不来自算法名。
- Box–Cox/Yeo–Johnson 是变换；逐步、最佳子集是搜索程序；Conformal 是区间封装，均不能独立称为完整回归模型。
- “曲线回归”必须拆成多项式、NLS、样条、LOESS、GAM、MARS 等具体结构。
- Tobit 处理删失潜变量，截断回归处理样本未进入，Heckman 处理特定非随机样本选择；三者不能互换。
- ZIP 与 Hurdle 的零生成机制不同；零多不能单独证明存在结构零。
- Beta 回归的经典支持集为 `(0,1)`；含精确 0/1 的分数响应可先考虑 fractional response 或边界扩展。
- 面板 FE/RE、动态 GMM、空间回归和生存回归的有效样本是独立组/事件/地点等结构量，不等于总行数。
- 传统 TWFE 事件研究在错位处理和异质效应下可能失真；需使用 cohort×event-time 或 group-time ATT 等稳健目标。
- ARIMAX/SARIMAX 的软件参数化可能不同；必须记录回归项是否被差分以及未来外生变量是否真实可得。
- 普通树、KNN 和多数局部平滑器不适合无依据的训练范围外外推。
- Conformal 在交换性条件下给边际覆盖，不自动给条件覆盖；时空、层级和时间依赖要用相容扩展。

## 5. 仍必须任务时动态核验

- 软件版本、默认参数、类别编码、正则化尺度、随机性和求解状态；
- 当前题目的特征可得时间、缺失机制、依赖结构和外推范围；
- 因果识别假设、空间权重矩阵、协整秩、删失机制和概率区间校准；
- 任何精度、速度、内存、排名或“某模型最好”的经验结论。

结论：主表可作为候选路由与审计清单，但不能替代对应专题、原始资料和当前任务的训练外证据。
