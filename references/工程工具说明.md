# 工程工具说明

运行位置由用户项目决定，以下路径均相对 Skill 根目录。PowerShell 工具需要 PowerShell 7；不自动安装软件或下载依赖。

| 工具 | 功能 | 是否写入项目 |
|---|---|---|
| scripts/route_knowledge.ps1 | 返回当前题型与阶段的读取集 | 否 |
| scripts/new_modeling_project.ps1 | 在新建或空目录创建最小项目与阶段状态 | 是，拒绝非空目录 |
| scripts/modeling_stage.ps1 | Status 查看；Check 查产物；Advance 推进状态 | 仅 Advance 写入，不自动创建备份 |
| scripts/freeze_results.ps1 | 对明确选择的结果文件建立 SHA-256 清单 | Freeze 写入新清单，拒绝覆盖 |
| scripts/verify_results.ps1 | 验证清单结构、范围、大小与文件哈希 | 否，不创建 results 目录 |
| scripts/validate_submission.ps1 | PDF 文件头、大小、文件名及可选匿名词预检 | 不修改项目；外部 PDF 工具可选 |
| scripts/build_submission.ps1 | 校验通过后创建本地审阅 ZIP 和清单 | 是，拒绝覆盖现有包或清单 |
| scripts/validate_skill_package.ps1 | 检查 Skill 结构、本地链接、资源路径与来源绑定 | 否 |

## 调用范例

`$SkillRoot` 和 `$ProjectRoot` 必须由当前任务解析，不使用维护者的个人路径。

```powershell
& "$SkillRoot/scripts/new_modeling_project.ps1" -Path $ProjectRoot -Contest Generic -Problem '用户确认的任务'
& "$SkillRoot/scripts/modeling_stage.ps1" -ProjectRoot $ProjectRoot -Action Check
& "$SkillRoot/scripts/freeze_results.ps1" -ProjectRoot $ProjectRoot -Paths 'results/metrics.json'
& "$SkillRoot/scripts/verify_results.ps1" -ProjectRoot $ProjectRoot
& "$SkillRoot/scripts/validate_submission.ps1" -PaperPath "$ProjectRoot/paper/solution.pdf" -Profile Generic
```

新一轮结果需要新清单路径，或先经授权保全旧清单；不要在审查时重新冻结以掩盖不一致。结果哈希只证明字节是否改变，不证明正文数字、实验设计或科学结论正确。

## 交付限制

赛事参数是规则快照的机械筛查，不是完整合规认证。PDF 预检不支持 Word，也不意味着国赛只允许 PDF。缺少 pdfinfo 或 pdftotext 时会报告未查范围；元数据、扫描页、图中文字、公式和版面仍需人工审查。

只有用户要求打包时才调用 build_submission。其输入必须是项目内明确列出的文件，不递归收集整个项目。本地审阅 ZIP 不自动上传，也不代替赛事要求的单 PDF 或独立支撑材料。
