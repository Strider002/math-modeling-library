# 问题识别与模型选择

## 1. 从题目动词识别任务

| 题目语言 | 主要任务 | 首选模型族 |
|---|---|---|
| 评价、排名、优选、综合水平 | 多指标评价 | TOPSIS、熵权、AHP、PCA、模糊评价、DEA |
| 预测、趋势、未来值 | 预测 | 回归、指数平滑、ARIMA、灰色预测、树模型 |
| 最大、最小、安排、调度、路径、配置 | 优化 | LP/MILP、非线性规划、网络优化、动态规划 |
| 分类、识别、判别、风险等级 | 分类 | 逻辑回归、LDA、树、SVM、集成学习 |
| 分群、画像、类型发现 | 聚类 | K-means、层次、DBSCAN、GMM |
| 传播、演化、增长、扩散、控制 | 机理模型 | ODE/PDE、差分方程、系统动力学 |
| 连通、中心、路线、关系 | 图与网络 | 最短路、最大流、匹配、中心性、社区发现 |
| 随机到达、等待、故障、库存风险 | 随机模型 | 排队、马尔可夫链、可靠性、随机规划 |
| 多主体行为、复杂流程、无法解析 | 仿真 | 蒙特卡洛、离散事件、Agent-based |
| 政策是否有效、因素是否导致结果 | 因果推断 | RCT、DID、RDD、IV、匹配；需强识别假设 |

实际赛题常是组合题。例如“预测需求后安排车辆”应拆成：
数据清洗 → 需求预测 → 优化调度 → 仿真/情景验证。

## 2. 模型选择六维标准

对候选模型按以下维度比较：

1. **目标匹配**：模型输出是否直接回答题目。
2. **数据匹配**：样本量、频率、变量类型、缺失和噪声是否允许。
3. **假设可信**：线性、独立、平稳、正态、无共线等假设是否近似成立。
4. **验证可能**：能否用留出集、历史事实、理论边界或专家知识验证。
5. **解释要求**：决策场景是否需要透明的参数和规则。
6. **成本约束**：时间、算力、实现风险是否合适。

可用简单决策矩阵给每项 1–5 分，但评分本身也要解释。

## 3. 模型链，而不是单一模型

成熟解法通常由四层组成：

1. **数据层**：清洗、变换、特征和不确定性；
2. **描述层**：EDA、相关结构、时空规律；
3. **核心层**：评价/预测/优化/机理模型；
4. **验证层**：对照、误差、敏感性、情景、外部一致性。

如果核心模型依赖另一个模型的输出，要传递不确定性。例如用预测需求做优化，不应只输入一个点预测，
还应使用预测区间或高、中、低情景。

## 4. 典型选择分支

### 评价问题

- 权重有明确专家偏好：AHP 或组合赋权；
- 希望由数据离散度确定权重：熵权、CRITIC；
- 指标强相关、希望降维：PCA/因子分析；
- 有投入和产出、评价效率：DEA；
- 边界模糊、等级语言化：模糊综合评价；
- 要按正负理想解排序：TOPSIS。

### 预测问题

- 样本很少、近似指数趋势：GM(1,1)，但必须检验与对照；
- 单变量、明显趋势/季节：指数平滑、SARIMA；
- 多变量、解释优先：线性/广义线性回归；
- 非线性、表格数据：随机森林、梯度提升；
- 长序列、大数据、复杂依赖：深度时序模型，但需强基线和严格回测。

### 优化问题

- 线性目标与约束：LP；
- 含“选或不选”、数量整数：MILP；
- 阶段递推和状态转移：动态规划；
- 网络路径、流、匹配：网络优化；
- 连续非线性且光滑：非线性规划；
- 多个冲突目标：加权和、ε-约束、Pareto；
- 参数有范围但无分布：鲁棒优化；
- 参数有概率分布或场景：随机规划；
- 规模大、精确算法太慢：启发式/元启发式，同时给下界或基准。

## 5. 可解释性与精度

不是二选一，而是分层处理：

- 用高精度模型产生预测；
- 用特征重要性、部分依赖、SHAP 等解释局部规律；
- 用简化模型总结可执行规则；
- 明确“解释关联”不等于“解释因果”。

高风险决策优先可审计、稳定和可校准；低风险自动化可更重视纯预测性能。

## 6. 常见错误

- 看到“评价”就机械使用 AHP + 熵权 + TOPSIS，而不解释为何需要三者；
- 模型名称很多，但彼此没有输入输出关系；
- 为了显得高级使用神经网络，却没有足够样本或对照；
- 只按拟合优度选模型，忽略预测误差、稳定性和业务代价；
- 为同一批数据反复调模型，再用同一批数据宣称泛化能力；
- 先选熟悉的模型，再强行把问题改写成适用形式。
