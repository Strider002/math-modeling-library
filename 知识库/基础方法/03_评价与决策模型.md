# 评价与决策模型

## 1. 评价问题的标准流程

1. 明确评价对象、目的和使用者；
2. 构建层次化指标体系，避免重复和遗漏；
3. 统一指标方向、单位与量纲；
4. 检查指标相关性和信息冗余；
5. 确定权重，并解释主观/客观信息来源；
6. 选择聚合或排序方法；
7. 做权重敏感性、排序稳定性和替代方案比较；
8. 输出分数、等级、短板和可执行建议。

## 2. 指标体系

好指标应具备：

- 与评价目标有明确逻辑关系；
- 可测、可比较、口径一致；
- 同层指标尽量独立；
- 数量适中；
- 覆盖效益、成本、风险、公平或可持续性等关键维度；
- 不把“结果指标”和高度重复的“过程指标”多次计权。

指标筛选可结合专家判断、相关分析、VIF、PCA、Lasso 或稳定性分析。

## 3. 权重方法

### AHP

适合层次清晰且需要专家偏好的情况。

步骤：建立层次 → 两两比较矩阵 → 求最大特征向量 → 一致性检验。

\[
CI=\frac{\lambda_{\max}-n}{n-1},\qquad CR=\frac{CI}{RI}
\]

通常要求 \(CR<0.1\)。AHP 的关键不是算权重，而是说明专家、尺度和一致性。
当阶数 \(n\le2\) 时随机一致性指标 \(RI=0\)，常规 \(CR\) 不定义或无需计算；不同阶数的 \(RI\)
取值要注明所用表的来源。

### 熵权法

指标差异越大，提供的信息越多，权重越大。它反映样本离散度，不等于真实重要性。

\[
p_{ij}=\frac{x_{ij}}{\sum_i x_{ij}},\quad
e_j=-k\sum_i p_{ij}\ln p_{ij},\quad
w_j=\frac{1-e_j}{\sum_j(1-e_j)}
\]

这里要求用于计算 \(p_{ij}\) 的值非负且每列和为正，通常
\(k=1/\ln n\)，并约定 \(0\ln0=0\)。常数列的差异系数为零，应删除或给零权重，
不能用随意小正数制造信息量。熵越大表示越均匀、差异信息越少；离散度仍可能来自噪声，
不等于真实重要性。详见 `知识库/进阶方法/22_数据分析与数据挖掘进阶.md`。

### CRITIC

同时利用指标标准差和与其他指标的冲突性。适合希望降低强相关指标重复计权的情况。

### 组合赋权

可将主观权重 \(w^{(s)}\) 与客观权重 \(w^{(o)}\) 组合：

\[
w=\alpha w^{(s)}+(1-\alpha)w^{(o)}
\]

\(\alpha\) 不能随意取 0.5；可依据专家可信度、交叉验证、稳定性或最小偏差确定。

## 4. TOPSIS

思想：方案应最接近正理想解、最远离负理想解。

步骤：

1. 指标正向化和标准化；
2. 乘权重得到加权矩阵；
3. 求正负理想点；
4. 计算欧氏距离 \(D_i^+,D_i^-\)；
5. 计算贴近度

\[
C_i=\frac{D_i^-}{D_i^+ + D_i^-}
\]

\(C_i\) 越大越优。

注意：

- 距离度量隐含指标可补偿；
- 结果依赖标准化和权重；
- 新增/删除方案可能改变理想点和排序；
- 应报告排序稳定性，而非只给最终名次。

## 5. PCA 与因子分析

PCA 用正交线性组合最大化方差，适合降维和处理强相关指标。
正式使用时必须继续读取 `知识库/进阶方法/27_主成分分析严谨方法卡.md`。

流程：数据审计与中心化 → 按尺度含义决定是否标准化 → SVD/协方差特征分解 →
按任务证据选择维数 → 明确定义主轴系数/得分/相关载荷 → 验证稳定性和下游用途。

注意：

- 方差大不必然意味着业务重要；
- 主成分正负号没有固有含义；
- 综合得分若按解释方差占比确定，只是数据依赖的方差权重，不是业务重要性；
- PCA 是无监督的，未必保留与目标最相关的信息。

因子分析强调潜在因子对观测变量的解释，通常需 KMO 和 Bartlett 检验，并可旋转以增强可解释性。

## 6. 模糊综合评价

适合“好、一般、差”等边界模糊的等级评价。

要素：因素集 \(U\)、评价集 \(V\)、权重 \(W\)、隶属度矩阵 \(R\)，综合结果
\[
B=WR
\]

上式对应加权平均型合成；若采用 max–min 等其他模糊合成算子，必须明确运算定义，不能只写符号 \(\circ\)。
关键是隶属函数来源。三角、梯形或高斯函数的阈值应来自标准、数据或专家，不可只为得到理想结果。

## 7. DEA

DEA 比较多个决策单元在多投入、多产出下的相对效率。

- CCR：假设规模报酬不变；
- BCC：允许规模报酬可变；
- 可分解技术效率与规模效率。

注意：

- 决策单元数量应明显大于投入产出指标数；
- 对异常值和测量误差敏感；
- 效率 1 是样本内相对有效，不是绝对最优；
- 指标方向和可控性要清楚。

## 8. 多准则决策的稳健性

至少做一种：

- 权重在合理区间内扰动；
- 使用 Dirichlet 或 bootstrap 生成权重；
- 比较等权、主观权重、客观权重；
- 比较 TOPSIS、加权和、VIKOR 等方法；
- 统计名次均值、方差、进入前 k 名概率；
- 检查阈值和标准化方法变化。

如果名次不稳定，应报告“候选集合”和关键分歧，而不是伪造唯一确定的排名。

## 9. 常见误区

- 指标越多越全面；
- 熵权就是“科学客观”的真实重要性；
- AHP 一致性通过就代表专家判断正确；
- 先用 PCA 降维，再把原指标权重与主成分权重混在一起；
- 只报告综合分，不解释各维度短板；
- 分数精确到很多小数，但原始评价尺度很粗。
