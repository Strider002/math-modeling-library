# 历年赛题端到端基准

本目录固定五类历史赛题的输入契约、必交产物和匿名评分表，用于以后比较“使用 Skill”与“不使用 Skill”的完整任务质量。它目前只证明基准基础设施可用，不证明 Skill 已提高获奖概率。

## 使用边界

- 仓库不复制赛题、附件或优秀论文全文；从 manifest 中的官方入口合法取得。
- 下载后记录文件名、字节数和 SHA-256，再锁定为某次基准运行的输入。
- Skill 组与对照组使用相同输入、时限、算力和评分表；评分前隐藏组别。
- 不以历史获奖论文为标准答案；只用它们做案例对照，并单独审计其中的不足。
- 未完成双组端到端运行和盲评时，结果状态必须保持“未执行”。

## 固定产物

每次运行使用项目状态机，至少交付问题范围、数据审计、模型与验证计划、复现说明、验证报告、冻结结果清单、论文 PDF 和提交审计清单。所有评分数字必须绑定评审记录与冻结产物哈希。

## 当前状态

五个案例已完成元数据和产物契约配置；原题附件、统一时限下的双组解答及盲评分尚未生成，因此不能报告效果提升。
