## 2. 官方会员流程

### 2.1 新账号与 Mathmodels 购买

1. 普通账号注册页要求 Name、Username、至少 8 个字符的 Password、Email、同意 Terms of Service 和 Captcha。
2. Mathmodels 有独立的订阅表单，要求 Username、Password、Email、姓名、学校/机构、学校层级、国家/地区、支付信息和 Captcha。
3. Mathmodels 总目录明确标价 **35 美元/年**，包含目录中的 problems、student papers、commentaries。
4. COMAP Individual Membership 页面另列：Full Membership 为 99 美元/年，Mathmodels 是 Full Membership 的可选 add-on，标价 28 美元。免费 Student/Educator Membership 不要求信用卡，但官方权益表没有把 Mathmodels 学生论文列入免费权益。
5. 官方接受主要信用卡和 PayPal；会员不会自动续费，过期前发送提醒。因此“去年能下载、今年登录后不能下载”可以由会员过期解释，但必须以 Profile 中的 membership status 为准。

官方依据：

- https://www.comap.org/component/users/registration?Itemid=101
- https://www.comap.org/membership/become-a-mathmodels-member
- https://www.comap.org/membership/individual-members
- https://www.comap.org/?id=67&view=article

### 2.2 账号“激活”的证据边界

官方公开帮助页只明确两件事：

- 可在 Profile 检查 membership status；
- 下载会员资源必须拥有 **active COMAP membership** 且已登录。

本次没有在公开官方页面找到“注册后必须点击某封激活邮件”的完整说明，且未提交虚构注册或支付。因此不得把“没有点激活邮件”写成用户的既定根因。对新购账号，正确核验顺序是：登录当前入口 → 打开 Profile 查看会员类型和有效状态 → 打开具体资源页检查红色下载按钮；若状态或订单未生效，再携带脱敏订单号联系官方帮助。

### 2.3 用户名/密码找回

- 忘记用户名：https://www.comap.org/component/users/remind?Itemid=101 。输入账号记录中的邮箱，用户名会发送到该邮箱。
- 忘记密码：https://www.comap.org/component/users/reset?Itemid=101 。输入账号邮箱，官方发送 verification code，收到后才能设置新密码。
- 若注册邮箱本身有问题，官方要求联系 COMAP，而不是反复新建账号。
- Advisor 的找回页完全独立，只接受竞赛 Advisor 注册邮箱：https://www.contest.comap.com/undergraduate/contests/mcm/forgot.php 。

## 3. 为什么 Advisor 账号不能直接当 Mathmodels 账号

| 比较项 | 竞赛 Advisor 系统 | COMAP/Mathmodels 会员系统 |
|---|---|---|
| 主机 | `contest.comap.com` | `www.comap.org`（旧 `mathmodels.org` 内容已迁入） |
| 登录标识 | Email Address | Username |
| 账号来源 | 注册 MCM/ICM Advisor | 创建 COMAP 账号或订阅 Mathmodels |
| 主要用途 | 注册队伍、结果、证书、队伍资料 | 会员资源、学生论文、评注 |
| 找回流程 | `contest.../forgot.php`，按 Advisor 邮箱 | `component/users/remind` / `reset`，按会员账号邮箱 |
| 匿名 GET Cookie | `PHPSESSID`，`Secure; SameSite=None` | 独立的 COMAP 会话 Cookie，`Secure; HttpOnly` |

COMAP 竞赛说明明确要求 Advisor 用注册竞赛时相同的邮箱和密码登录；COMAP Member Login 则明确要求 Username 和 Password。官方没有发布二者 SSO 或自动同步说明。故应按两个独立账号系统处理，即使同一个人恰好使用相同邮箱或密码。

官方依据：

- https://www.contest.comap.com/undergraduate/contests/mcm/instructions.html
- https://www.contest.comap.com/undergraduate/contests/mcm/login.php
- https://www.comap.org/member-login

## 4. Cookie、JavaScript 与认证跳转

1. 当前 COMAP Member Login、注册、重置、购买页面在匿名访问时都会下发第一方 Secure 会话 Cookie；竞赛 Advisor 页面另下发自己的 `PHPSESSID`。若浏览器完全禁止这两个站点的第一方 Cookie，登录状态可能无法保持。该项是 HTTP 响应的现场观察，不是对用户浏览器设置的推断。
2. 普通账号注册、密码重置和 Mathmodels 购买表单都明确显示：`JavaScript is required for CAPTCHA verification to submit this form.` 因此禁用 JavaScript、脚本拦截器拦住 Captcha、或 Captcha 未加载，会直接阻止注册/重置/购买提交。
3. 当前资源页的匿名认证跳转是：资源页 → `login here` → `https://www.comap.org/member-login`。不需要使用 Advisor Login。
4. 旧 `mathmodels.org` 登录书签存在错误重定向；这是服务端 URL 迁移问题，不能通过清浏览器密码解决。应先切换到当前 `comap.org/member-login`。

- 2022 Mathmodels 目录按题名给出的 D/F 资源数为 D7、F4，而 2022 官方结果页的 Outstanding 题号统计为 D4、F7；

## 8. 每日回溯优先级

1. **P0：自上次成功检查日至当前日的增量。** 检查当年结果页、Mathmodels 总目录、具体资源页的 Student Papers/Commentary 状态；若电脑离线，按日期补查而不是只查“今天”。
2. **P1：2026 → 2024。** 最新、目录元数据完整，先处理尚未审全文的 Outstanding；2024 D 明确跳过队号 `2417004`。
3. **P2：2023 → 2016。** 六题制为主且官方结果较完整；2023 包含 Y/Z，2022 和 2023 必须先处理上述数量冲突。
4. **P3：2015 → 1999。** 题制不同，使用 `previous-contests.php` 的实际年度链接逐年核验，不假定总是 A—F。
5. **P4：1998 → 1985。** 以全历史矩阵为导航；主要为 MCM A/B，目录论文数较少，可作为低频补库批次。

每篇进入方法论前仍必须满足：官方结果确认奖项 → 合法取得全文 → 逐页阅读 → 公式/数据独立核验 → 代码或小例验证 → 记录局限。目录出现新文件只触发候选登记，不直接触发知识吸收。
