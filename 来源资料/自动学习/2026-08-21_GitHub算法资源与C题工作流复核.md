## 3. Expectorpatro 增量审计

### 3.1 模拟退火

网站给出的最小化接受率

\[
\alpha_T(x,y)=\min\{1,\exp[-(f(y)-f(x))/T]\}
\]

可作为常见对称提议下的 Metropolis 接受规则。若提议分布 \(q(y\mid x)\) 不对称，而目标是保持
\(\pi_T(x)\propto e^{-f(x)/T}\) 的不变分布，则一般需使用含提议比的 Metropolis—Hastings 接受率：

\[
\alpha_T(x,y)=\min\left\{1,
\exp\left[-\frac{f(y)-f(x)}{T}\right]\frac{q(x\mid y)}{q(y\mid x)}
\right\}.
\]

原文先允许一般 \(q_n(\cdot\mid x)\)，随后无条件使用简化式，条件缺失。原文“降温策略只需要
单调下降并趋于 0”的说法也只能描述一个有限预算启发式框架，不能支撑全局收敛；理论收敛还依赖
状态空间、可达性、每温度停留和足够慢的冷却等条件。

Rastrigin notebook 的静态审查：

- 目标函数和已知全局最小点结构正确；
- 每步随机扰动一个坐标，并用重复反射保持在盒约束内；
- 使用 `simanneal.Annealer`、`Tmax=30`、`Tmin=1e-4`、60,000 步和一个 Python 随机种子；
- `history` 由重写的 `update` 记录的是更新时点，不是每次内部移动；
- 只给单种子演示，没有多次运行分布、随机/局部基线、预算公平比较或最优性证书。

当前本地 Python 环境没有 `simanneal`，因此本轮没有声称重新执行该 notebook。代码只能作为
演示线索，不进入竞赛级结果证据。

### 3.2 遗传算法

编码、选择、交叉、变异和精英保留的基本结构成立，但必须绑定表示：

- 单点交叉不适用于一般排列编码；
- 算术交叉只在凸可行域中自动保持可行；
- 变异概率必须区分“每个个体触发概率”和“每个基因触发概率”；
- 精英保留只保证已记录的最好目标不变差，不证明总体收敛或全局最优；
- 若每轮成对加入两个子代，必须处理 \(N-e\) 为奇数的情况，避免种群超额。

Rastrigin notebook 的静态审查：

- 使用 DEAP；盒约束为凸集，因此算术交叉保持可行；
- 个体级变异以 0.2 概率触发，触发后只扰动一个坐标并截断边界；
- 适应度比例 \(1/(1+f)\) 在本例 \(f\ge0\) 时有效，不能直接推广到可能 \(f\le-1\) 的目标；
- 本例 \(N-e=118\) 为偶数，不触发伪代码的奇数子代问题；

### 3.3 KNN、KD-tree 与 Ball-tree

新增 KNN 分类/回归、距离加权和基于距离下界剪枝的说明。可吸收的核心是：

### 3.4 神经网络

`nn.tex` 从 1,279 行增至 1,459 行，新增 194 行、删除 14 行。新增的 BatchNorm、LayerNorm、
残差连接和 inverted Dropout 公式主体可用：

\[
\widehat x_{ij}=\frac{x_{ij}-\mu_{\mathcal B,j}}
{\sqrt{\sigma_{\mathcal B,j}^2+\varepsilon}},\qquad
y_{ij}=\gamma_j\widehat x_{ij}+\beta_j,
\]

\[
y=x+F_\theta(x),\qquad
\widetilde h_j=\frac{m_j}{q}h_j,\quad m_j\sim\operatorname{Bernoulli}(q).
\]

需要补充的实现边界：

- 归一化轴由张量语义决定，不能仅凭“输入是矩阵”选择；
- BatchNorm 的运行均值/方差、动量和方差估计必须绑定框架版本；
- train/eval 模式切换会改变 BatchNorm 与 Dropout 行为；
- 残差相加要求形状一致，投影支路、激活和归一化位置会改变“恒等路径”；
- 这些结构改善某些优化问题，但不保证收敛、泛化或优于浅层基线。

旧版已隔离的 GRU 正文—伪代码冲突仍需按当前源重新定位；不能因为后续新增章节就撤销。

### 3.5 PCA

新版重构没有消除以下问题：

1. 变量 \(X_j\) 被前 \(k\) 个主成分表示的平方相关和，分母应绑定 \(X_j\) 的方差
   \(\sigma_{jj}\)，源码一处写成随主成分索引变化的 \(\sigma_{ii}\)；
2. 算法同时写 `Σ=AΛA^T`、取 `A` 的前 \(k\) 行并计算 `Y=A_kZ`，没有统一“特征向量按列”
   与“样本按行/列”的方向；
3. “发现共线性就先删除或合并变量”不是 PCA 的必要步骤；
4. 85% 累计方差只能是经验候选，不是普适最优维数；
5. “PCA 无法解决重复信息”表述过强。精确重复变量会改变变量加权几何，但 PCA 本身仍能把低秩
   相关结构压缩到更少维度。

主库 `知识库/进阶方法/27_主成分分析严谨方法卡.md` 的统一 \(n\times p\) 方向、SVD 实现、重构误差和维数验证
继续优先于该网页。

### 3.6 凸集与多面体

新增源码中存在可直接判定的记号或证明错误：

- Minkowski 和的条目左侧误写 `E_1+E_1`，集合定义却使用 \(E_1,E_2\)；
- 多面体 `{x:Ax≤b,Cx=d}` 的 \(b,C,d\) 维数与 \(A\in\mathbb R^{m\times n}\)、
  \(x\in\mathbb R^n\) 不匹配；一致写法应为
  \(b\in\mathbb R^m,C\in\mathbb R^{p\times n},d\in\mathbb R^p\)；
- 证明闭半空间凸性时应取 \(\theta\in[0,1]\)，原文写 \(\theta\ge0\)；
- 椭球等价证明把二范数和二范数平方混写：
  \(u^\top u=\lVert u\rVert_2^2\)，不是 \(\lVert u\rVert_2\)。

这些内容只登记为隔离错误，不进入 `知识库/基础方法/19_数学基础与统计理论补充.md`。

### 3.7 时间序列和随机模拟实验

ARIMA 实验的正确价值是“图形/单位根线索 → 低阶候选 → 残差诊断”，且正文明确 Ljung—Box
不证明独立、正态或同方差。竞赛使用仍须增加滚动训练外预测；单一全样本拟合和向前预测不能证明
泛化。ADF 软件给出的 `p=0.0100` 是报告下限，不能解释为精确 p 值。

逆变换指数分布和接受—拒绝生成 Beta(2,5) 的公式、接受常数
\(M=1536/625=2.4576\)、理论接受率 \(1/M\) 及经验 CDF 核验相互一致。固定种子只保证该实现路径
的可复查性，不证明随机数发生器跨语言/跨版本逐位一致。

### 3.8 树集成比较实验

示例把乳腺癌分类和糖尿病回归各划分为训练/验证/测试，验证集选超参数，测试集作最终比较，角色
基本清楚。仍需注意：

- 单次 60/20/20 划分方差较大，不等价于嵌套交叉验证；
- 选出模型后没有在训练+验证上重拟合，这是保守但需说明的选择；
- 分类阈值固定为默认阈值，未做成本、校准或不平衡敏感性；
- 四个模型的网格大小不同，搜索预算不完全对称；
- 测试比较结束后不得再据测试结果调网格或阈值。

## 5. 国赛 C 题可复用结论

结合本库已核验的 2022—2024 C 题案例，只保留下列跨题稳定方法：

1. 组成数据、时间序列、层级/重复测量、删失/截尾等结构先于算法；
2. 数据—统计模型—预测—优化必须画成有向数据流，每层写明误差与下游用途；
3. 朴素预测、简单回归、业务规则、贪心或精确小例是必需基线；
4. 预测进入决策时，用场景、分位数或训练外残差传播不确定性；
5. 关联规则、聚类、PCA 和综合评价只有在对应交付项需要时使用；
6. 启发式必须与精确小例、下界或简单策略比较，多随机种子报告分布；
7. 最终答案检查现实顺序、可用信息、约束 slack、单位、极端情景和执行成本。

这些是工作流结论，不代表未来 C 题必然出现预测、机器学习或优化。
