## 3. 逐项公式与逻辑复核

| 编号 | 网页位置 | 判定 | 问题与正确边界 |
|---|---|---|---|
| W-NN-01 | Definition 17.26 | 需修正 | 把每层激活都定义为逐元素函数，但后文 softmax 是向量耦合映射；输出层也常用恒等映射。应区分隐藏激活与任务输出映射。 |
| W-NN-02 | Definition 17.26 | 错误 | 依网页自身 \(L\) 个变换层的记号，\(L=2\) 已有一个位于输入和输出间的隐藏变换层；“\(L>2\) 才有隐藏层”不成立。 |
| W-NN-03 | note 17.15 | 术语错误 | 含偏置的多层复合是仿射映射，不是严格线性映射；只有全部偏置为零时才是线性映射。 |
| W-NN-04 | Definition 17.32 | 轻微记号错 | 先写输入向量 \(z=(x_1,\ldots,x_n)^\top\)，公式又写 \(\sigma(x)_i\)，应统一一个向量符号。公式本身的 softmax 分母正确。 |
| W-NN-05 | notes 17.16—17.17 | 过强 | sigmoid/softmax 的值域满足概率形式，但预测值能否作为概率还取决于目标、损失、采样、分布和校准，不能仅由范围推出。 |
| W-NN-06 | Definition 17.34 | 错误 | 批大小条件写成 \(|\mathcal B_{er}|=B,\;i=1,\ldots,M-1\)，索引应为 \(r\)。最后一批通常小于等于 \(B\)。 |
| W-NN-07 | §17.6.1.3 | 需定名 | 描述的是每轮随机排列后的无放回 random reshuffling，不等同于每步独立有放回抽样的经典随机版本。 |
| W-NN-08 | §17.6.1.4 | 缺项 | 没写明小批损失是求和还是平均；这会改变梯度尺度以及学习率与批大小的关系。 |
| W-NN-09 | §17.6.1.5 | 过度简化 | 深层梯度由 Jacobian 乘积及其方向/奇异值决定，不是只数“多数标量导数是否小于 1”。 |
| W-NN-10 | Definition 17.35 | 公式通过、解释过强 | 全局范数裁剪公式正确，但“为参数变化提供上界”只对简单 SGD 可直接得到 \(\|\Delta\theta\|\le\eta c\)。动量、Adam、权重衰减还有状态或额外项。 |
| W-NN-11 | §17.6.2 | 条件缺失 | 变长序列若含 padding，直接取张量最后状态或对所有时间步求均值会污染表示，必须按真实长度/mask 汇总。 |
| W-NN-12 | §17.6.2.2 首段 | 过强 | LSTM 主要改善长期依赖和衰减误差流，不能保证解决梯度消失，更不能自动解决梯度爆炸。 |
| W-NN-13 | LSTM 公式 | 条件通过 | 所列现代无 peephole LSTM 公式在其记号下自洽；但原始 1997 LSTM 与现代 forget gate 版本有历史差异，不能笼统称原始唯一形式。 |
| W-NN-14 | LSTM 解释 | 需补边界 | 门值和候选有界，但 cell state 是加法累积，不必然有统一上界。本次构造合法门近 1 的 20 步小例得到 \(c_{20}=19.9999995672\)。 |
| W-NN-15 | GRU 正文与 Algorithm 17.8 | 确定冲突 | 正文为 \(h_t=z_t\odot h_{t-1}+(1-z_t)\odot\tilde h_t\)，算法框却把两系数反转。按正文“\(z\) 越大越保留旧状态”的约定，Algorithm 17.8 错。数值反例为 0.3 对 -0.3。 |
| W-NN-16 | GRU 与软件 | 版本边界 | PyTorch 当前候选状态把 reset gate 作用于隐藏线性变换及其偏置之后，与原始论文“先门控旧状态再乘隐藏矩阵”不同。 |
| W-NN-17 | Definition 17.39 | 术语错误 | 核未翻转，数学上是互相关。深度学习库惯例把互相关称卷积，但知识库必须显式说明。多通道完整式还需要输入通道求和、输出通道和偏置。 |
| W-NN-18 | Definition 17.39 | 记号/边界缺失 | \(X(i+u-1;j+v-1)\) 使用分号且未定义输出索引范围；靠近边界时须先规定 padding。 |
| W-NN-19 | note 17.20 | 条件通过 | stride=1、忽略边界且使用一致平移时有平移等变；padding、裁切、步幅与下采样会破坏或削弱严格性质。 |
| W-NN-20 | Definition 17.41 | 需补边界 | 池化窗口与算子定义可用，但未写通道独立语义、输出尺寸、padding、dilation/ceil 约定和 max 并列点的梯度实现。 |
| W-NN-21 | note 17.21 | 过强风险 | 池化可能降低对小位移的敏感性，但不保证对任意输入严格平移不变。 |
| W-NN-22 | note 17.22 | 条件通过 | 输出尺寸只对 stride=1、dilation=1、对称整数 padding 成立；一般公式还需 floor、stride 和 dilation。 |
| W-NN-23 | §17.6.3.4 | 经验性描述 | “前层边缘、后层部件”等是常见经验解释，不是每个 CNN 的定理；现代 CNN 也不一定使用池化。 |
| W-NN-24 | 全节 | 重大缺项 | 没有感知机基线、一般前向/反向传播推导、输出—损失契约、MSE/BCE/CE、Adam、weight decay、dropout、早停、梯度检查、校准和竞赛验证协议。 |
| W-NN-25 | 全节/计算实验 | 事实核验 | 没有神经网络可执行例题代码；计算实验均为树模型。 |
