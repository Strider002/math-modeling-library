# Boston Housing 树模型与 XGBoost 复盘

## 任务信息

- 题目/项目：Boston Housing 数据集的 CART、随机森林与 XGBoost 分析
- 日期：2026-08-09
- 数据范围：506 个历史普查分区，13 个自变量，目标为 `MEDV`
- 原始数据路径/版本/SHA-256：`D:\数学建模\树模型、XGBoost\data\raw\housing.csv`；`BAADF72995725D76EFE787B664E1F083388C79BA21EF9A7990D87F774184735A`
- 代码提交或归档版本：项目目录中的 `boston_tree_xgboost_analysis.py` 与 `analysis_summary.json`
- 软件、依赖与求解器版本：Python 3.14.4，pandas 3.0.3，NumPy 2.4.6，scikit-learn 1.9.0，XGBoost 3.4.0
- 最终交付：Quarto 源文件、自包含 HTML、完整脚本、逐样本预测、表格、图形和审计日志

## 问题与模型链

- 任务类型：小样本表格回归、树模型比较、训练外验证与伦理敏感性
- 最终模型链：数据审计 → 均值/线性基线 → CART → 随机森林 → XGBoost → 独立测试 → 重复嵌套 CV → 配对 bootstrap → 残差/上限压力测试 → 删除伦理变量敏感性
- 子模型之间的输入输出：所有模型使用同一 13 列特征与同一固定测试集；模型输出连续 `MEDV` 预测，验证模块汇总 RMSE、MAE、R²、偏差和逐样本残差
- 选择理由：单树提供规则基线，随机森林降低单树方差，XGBoost逐轮拟合残差结构；均值与线性回归防止复杂模型无有效增益

## 最终结果

- 关键数值：固定测试集上 XGBoost RMSE 2.774、MAE 1.961、R² 0.892；随机森林 RMSE 3.349；CART RMSE 4.312
- 相对基线提升：XGBoost 测试 RMSE 相对 CART 降低约 35.7%，相对均值基线降低约 67.6%
- 不确定区间：XGBoost 测试 RMSE 配对 bootstrap 95% 区间 [2.171, 3.385]；XGBoost 减随机森林的 RMSE 差区间 [-1.567, 0.350]
- 最终建议：教学复现时采用删除 `B` 的 XGBoost，并保留随机森林作为近似性能对照；不得用于现实住房、信贷或人口群体决策

## 验证证据

- 数据外验证：固定 102 条独立测试集；另做 5 折 × 2 次重复嵌套交叉验证
- 验证划分索引或生成规则：随机种子 `20260809`，划分索引保存为 `outputs/tables/split_assignments.csv`
- 残差/误差：XGBoost 对 `MEDV<50` 的测试 RMSE 为 2.531；`MEDV=50` 的 2 条样本 RMSE 为 8.497，平均低估 7.052
- 敏感性：删除 `B` 后 XGBoost 训练内 CV RMSE 3.324、测试 RMSE 2.729；删除 `B` 与 `LSTAT` 后测试 RMSE 3.351
- 稳健性：重复嵌套 CV 中 XGBoost RMSE 3.135±0.356，随机森林 3.356±0.451；XGBoost 平均居首，但两者差异不宜夸大
- 极端情景：目标上限 `MEDV=50` 单独评估，揭示高价端系统性低估
- 公式—代码手算/不变量检查：XGBoost 使用 `reg:squarederror` 与正增益定义；指标由 `verify_project.py` 从逐样本预测独立复算
- 论文表格与代码输出一致性：验证脚本核对指标、划分数量、哈希、嵌套 CV 行数、HTML 关键数字和内嵌资源

## 有效做法

1. 固定测试集与重复嵌套 CV 同时使用：前者给出清晰最终估计，后者检查单次划分偶然性。
2. 对同一测试样本做配对 bootstrap，直接报告模型误差差值；这阻止把 XGBoost 相对随机森林的点估计优势夸大为确定优势。
3. 把 `MEDV=50` 作为压力组而非异常删除；整体指标因此没有掩盖高价端失效。
4. 置换重要性放在独立测试集上，并与删除伦理变量的重新调参实验配合，而不是只报告训练内不纯度重要性。

## 失败尝试

| 尝试 | 失败表现 | 原因 | 何时可能有效 |
|---|---|---|---|
| 直接把原始 `housing.csv` 交给通用 CSV 审计器 | 被解析为 1 列文本、505 行 | 原文件无表头且用连续空白分隔，不是标准逗号 CSV | 输入本身为规则 CSV/TSV 时 |
| 仅用单次测试点估计排序 XGBoost 与随机森林 | 容易得出“XGBoost 明显更优”的过强结论 | 小测试集造成模型差值区间跨 0 | 样本更大且差值区间稳定远离 0 时 |
| 把 `MEDV=50` 当普通尾部观测汇总 | 整体 RMSE 掩盖高价端低估 | 目标存在记录上限且测试组仅 2 条 | 目标未删失、尾部样本充分时 |

## 最敏感与最危险的假设

- 参数/输入：`LSTAT`、目标上限、随机/空间划分方式
- 假设：随机划分足以近似同分布新分区；现实部署分布与历史样本一致；`MEDV=50` 可当普通连续目标处理
- 失效后影响：空间泄漏会高估泛化；分布漂移使树模型无法外推；目标截断导致高价端误差被系统性低估
